# P1-DELIVERY-CHECKLIST

Priority: P1
Scope: `packages/web/**`

## Rule
- 完成开发任务前，应执行最小交付检查。
- 检查项至少包括：
  - 仅使用 TypeScript 且无 `any`。
  - 命名与目录分层符合约定。
  - 样式优先使用 Tailwind 与既有能力。
  - UI 复用顺序符合组件分层规则。
  - 请求接口优先 `$req`、`$api`，避免重复封装直连请求。
  - 项目相关逻辑与跨项目逻辑落点正确。
  - 表单具备校验与错误提示。

## Non-Goals
- 不强制每次变更都触发全量构建。
- 不替代代码评审流程。

## Exceptions
- 紧急修复可缩减检查项，但必须在后续补齐。

## Checks
- 在变更说明中记录已执行的检查项。
- 评审时核对是否覆盖核心检查项。
